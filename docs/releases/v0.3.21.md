Cabane 0.3.21 updates the Home Assistant panel to workspace contract revision 21.

## Contract changes and upgrade impact

### Contract revision 19: Keep native glow selections stable across model variants

- Existing homes and immutable GLB selections remain supported. Native keyed emissiveSurfaces require the updated frontend and matching HA panel. Old native ordinals remain saved but inactive until explicitly reselected. No asset, binding or schema-version migration is required.

### Contract revision 20: Keep dense model lighting renderable and isolate broken optional illumination

- Existing authored sources, sample counts, model identities and connections remain unchanged. Older panels can reject valid lighting above eight samples or with no physical output; update HACS, restart Home Assistant and reload the frontend. Runtime recovery disables only malformed optional lighting without rewriting saved data.

### Contract revision 21: Add persistent Arrange item groups

- Existing homes remain supported. Homes saved with scene-item group metadata require an updated frontend and matching Home Assistant panel. Groups preserve individual models, lighting and connections without a schema-version or asset migration; older clients retain unsupported-field protection.

## Update

Update Cabane in HACS, restart Home Assistant, then reload your browser or Companion app. Keep saved workspaces unchanged; no manual JSON edits are needed. Older clients continue to block unsupported data to protect it.

For manual installation, extract the complete cabane.zip release asset into /config/custom_components/cabane/, restart HA and reload the frontend.

This release passed producer verification, native-panel browser checks, representative-scale checks, integration tests and package validation with synthetic HA data. Live household and Companion acceptance are separate.
