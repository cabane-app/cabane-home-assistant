Cabane 0.3.26 updates the Home Assistant panel to workspace contract revision 35.

## Contract changes and upgrade impact

### Contract revision 32: Adapt linear model lighting to transformed instance length

- Adaptive maxSpacingMeters on strip sources requires the matching frontend and Home Assistant panel. Existing fixed-sample strips remain supported without migration.

### Contract revision 33: Add per-face wall tiles, wallpaper and custom images

- Projects using optional wall faceFinishes require the matching frontend and Home Assistant panel. Existing paint-only projects and adaptive lighting from revision 32 remain supported. Optimized custom images travel inside the existing workspace document without an asset or backend migration; older clients retain unsupported-data protection.

### Contract revision 34: Support optional named poses for imported GLB models

- Existing imported models stay static without migration. Projects with custom-model pose mappings require the matching frontend and HA panel. GLB bytes and the asset protocol are unchanged.

### Contract revision 35: Add pool types and adjustable basin height or depth

- Existing pools keep their in-ground geometry and 1.5 m depth without migration. Projects storing pool type or height settings require the matching frontend and Home Assistant panel.

## Update

Update Cabane in HACS, restart Home Assistant, then reload your browser or Companion app. Keep saved workspaces unchanged; no manual JSON edits are needed. Older clients continue to block unsupported data to protect it.

For manual installation, extract the complete cabane.zip release asset into /config/custom_components/cabane/, restart HA and reload the frontend.

This release passed producer verification, native-panel browser checks, representative-scale checks, integration tests and package validation with synthetic HA data. Live household and Companion acceptance are separate.
