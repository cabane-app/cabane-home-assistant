Cabane 0.3.24 updates the Home Assistant panel to workspace contract revision 30.

## Contract changes and upgrade impact

### Contract revision 24: Keep homes usable when catalog models are unavailable

- Unavailable models now render as placeholders while preserving item IDs, placements and connections. Update Cabane in HACS, restart Home Assistant and reload to get this recovery behavior. Structural errors remain blocked; no saved fields or schema versions change.

### Contract revision 25: Add optional display names for walls, doors, windows and passages; preserve architectural and binding identities.

- Older Cabane clients reject projects containing wall or opening name fields. Update the Home Assistant integration and reload all clients before opening a renamed project.

### Contract revision 26: Add sloped terrain with home-wide corner heights

- Existing homes retain flat terrain. Homes saved with home.terrain require the updated frontend and matching Home Assistant panel. Older clients retain unsupported-field protection. No floor, asset or binding migration is required.

### Contract revision 27: Warn about disconnected terrain exits and stabilize terrace clipping

- No saved fields or migrations change. Terrain exit diagnostics are warning-only and do not block Save. Update the frontend and matching Home Assistant panel for these warnings and the terrace/basement clipping fix.

### Contract revision 28: Allow shortcuts to devices outside rooms

- No saved fields change. Outside-room device shortcuts now validate and open device controls directly. Older panels reject these targets as lacking a room sheet and require the matching update before using them.

### Contract revision 29: Connect stairs directly to terrain

- Existing floor-to-floor stairs remain compatible. Terrain stairs store one floor and a terrain endpoint and require the matching panel update. Their rise, landing validation and Walk route follow the current terrain without adding a storey.

### Contract revision 30: Connect stairs to terrain and add masonry stair styles

- Existing floor-to-floor stairs and omitted styles remain compatible. Terrain connections and Concrete or Stone styles require the matching frontend and Home Assistant panel. Terrain rise, landing validation and Walk follow the current grade without adding a storey. No migration is required.

## Update

Update Cabane in HACS, restart Home Assistant, then reload your browser or Companion app. Keep saved workspaces unchanged; no manual JSON edits are needed. Older clients continue to block unsupported data to protect it.

For manual installation, extract the complete cabane.zip release asset into /config/custom_components/cabane/, restart HA and reload the frontend.

This release passed producer verification, native-panel browser checks, representative-scale checks, integration tests and package validation with synthetic HA data. Live household and Companion acceptance are separate.
