Cabane 0.3.34 updates the Home Assistant panel to workspace contract revision 49.

## Contract changes and upgrade impact

### Contract revision 47: Save adjustable map borders with the home

- Homes with edited map borders store four ground margins. Update older Cabane clients and the Home Assistant panel before opening these homes.

### Contract revision 48: Add optional flat ceiling colors

- Existing homes retain their ceiling appearance. Homes with a flat ceiling color require updated Cabane clients and the matching Home Assistant panel; older clients reject the new field. No migration is required.

### Contract revision 49: Support bifold doors and multi-pane sliding windows

- Existing openings need no migration. Projects using bifold doors or sliding windows require the matching frontend and Home Assistant panel; older clients reject these operations.

## Update

Update Cabane in HACS, restart Home Assistant, then reload your browser or Companion app. Keep saved workspaces unchanged; no manual JSON edits are needed. Older clients continue to block unsupported data to protect it.

For manual installation, extract the complete cabane.zip release asset into /config/custom_components/cabane/, restart HA and reload the frontend.


This release passed producer verification, native-panel browser checks, representative-scale checks, integration tests and package validation with synthetic HA data. Live household and Companion acceptance are separate.
