Cabane 0.3.14 brings the latest editor and Home Assistant controls to the sidebar panel.

## What's new

- Tap lights in the orbit view to toggle them; hold dimmable lights to adjust brightness.
- Use the shared Properties panel across Construct and Arrange, with clearer issue navigation and Locate controls.
- Change a selected room's floor finish directly from its palette. Floor menus now handle input and focus correctly inside Home Assistant.
- Search the full Arrange catalog and place blinds on glazed sliding doors.
- Find saved Home Assistant homes directly in the workspace library. Room controls list shared lights once.
- Keep upward lamp illumination near walls and receive the latest panel stability fixes.
- Download personal GLB models more efficiently, with bounded range reads and cached integrity verification. The integration also includes its Cabane icon and clearer setup guidance.

## Compatibility and source

Workspace contract revision 10 is unchanged. Existing saved homes remain compatible; no migration or manual JSON edits are needed.

The native panel is built from [cabane-app/cabane at eab84d8](https://github.com/cabane-app/cabane/commit/eab84d8c392ac96e20def3c4b07dcdf79a31f8d2), the new Cabane source repository. HACS continues to use [cabane-app/cabane-home-assistant](https://github.com/cabane-app/cabane-home-assistant).

Integration code remains MIT-licensed. The bundled frontend is distributed under PolyForm Noncommercial 1.0.0, with its license and third-party notices included in `frontend/`.

## Update

Update Cabane in HACS, restart Home Assistant, then reload your browser or Companion app.

For manual installation, extract the complete `cabane.zip` release asset into `/config/custom_components/cabane/`, restart HA and reload the frontend.
